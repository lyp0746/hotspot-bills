# 读者说明（《热点的账单》）

**这本书怎么用？** 三章，每张诊断卡都可独立使用：

- 学方法 → 第一章（五把尺子 + 诊断卡模板）；
- 看数据从哪来 → 第二章 + 附录 C；
- 直接看案例 → 第三章（12 张知乎卡 + 3 张 X 卡 + 6 张近期卡）；
- 自己诊断 → 附录 A 的模板。

**最简用法**：遇到任何热点，先只问两个问题——（1）大家在争的是事实还是诠释？（2）各方各让出了哪一个顶点？

**不包含**：采集脚本、原始数据（见本仓库）。
