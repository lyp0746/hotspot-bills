# 读者说明（《热点的账单》）

**这本书怎么用？** 十九章，每张诊断卡都可独立使用；可以从任何一章进入：

- 学方法 → 第一章（六把尺子 + 诊断卡模板）；
- 看数据从哪来 → 第二章 + 附录 C；
- 直接看案例 → 第三章（26 张主卡 + 3 张补卡）、第四章、第五章、第十三章；
- 看复盘与自检 → 第六章、第七章、第八章；
- 看长卡与最新案例 → 第十四章、第十九章；
- 自己诊断 → 第九章 + 附录 A 的模板。

**最简用法**：遇到任何热点，先只问两个问题——（1）大家在争的是事实还是诠释？（2）各方各让出了哪一个顶点？

**发布包内容**：印刷版 PDF、电子阅读版 PDF、EPUB 3、网页版、Markdown、封面、数据来源说明。
**不包含**：采集脚本、原始数据（见本仓库）。
