# 数据来源与口径

## 1. 知乎（中文）

- **来源**：`github.com/lonnyzhang423/zhihu-hot-hub`，每日热榜存档 `archives/YYYY-MM-DD.md`（每小时抓取、按天归档）。
- **采集**：2025-10-16 ~ 2026-10-16，成功 **338 天**；去重后 **2875 个不同话题**。
- **排序口径**：一个话题**上过多少次榜**（"上榜天数"）。跨时间可比，作为"被持续讨论程度"的代理变量。
- **产出**：`data/year_zhihu.json`（原始）、`data/year_events.md`（前 120 排行）。

## 2. X / Twitter（英文 & 日文）

- **来源**：twtData 免费历史趋势存档 `twtdata.com/twitter-trends/<country>/<MM-DD-YYYY>/`。
- **国家**：usa、united-kingdom、japan。
- **采集**：每 14 天采样一天，共 **27 个采样日 × 3 国 = 81 个"国家—日"**；每日最多保留前 50 条趋势。
- **技术**：该站有 Cloudflare 保护，普通 HTTP 客户端会被 403；须用无头浏览器（Chrome）加载页面、等待其脚本渲染趋势表格。见 `analysis/collect_x_history.py`。
- **产出**：`data/year_x.json`、`data/year_x_events.md`。
- **另存**：当期全球/美/印快照 `data/x_trends_snapshot.json`。

## 3. 其它当期来源（对照）

- 今日头条热榜、B 站热门、百度热搜：`analysis/collect.py` → `data/hotlists.json`。

## 4. 必须承认的局限

1. **平台 ≠ 公众**：知乎/X 用户不代表整体人口。
2. **热度 ≠ 重要性**：算法偏好争议与情绪。
3. **天数 ≠ 因果**：上榜多只说明讨论得久。
4. **X 采样稀疏**：每 14 天一采，会漏掉只有一两天的短促趋势；日本趋势含日文，未做翻译。
5. **未验证具体事实**：本书不核对事件细节，只诊断讨论结构。

## 5. 合规

只采集公开可见内容；不采集私信与可识别个人身份的信息；低频、带缓存、失败即停，不绕过风控。
