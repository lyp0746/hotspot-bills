一本**通俗诊断读本**：把同系列研究的六个核心（看见、记住、跟上、选择、讲述、临界），变成一套诊断公共讨论的通用方法，并对**过去一年真实发生过的热搜事件**逐一开出"诊断卡"。

---

## 一句话主张

> **热搜是压缩后的选择性真实；看懂一个热点，不是选对一边，而是看清它让出了什么。**

每张诊断卡都回答六个问题：在**划什么线**（看见）、被压成**什么标签**（记住）、**快钟慢钟**差多少（跟上）、各方**让出了哪个顶点**（选择）、争吵在**哪一层**（讲述）、有没有**跨过门槛**（临界）。

## 数据是真实的

- **知乎**：每日热榜存档（`lonnyzhang423/zhihu-hot-hub`），采集区间 **2025-10-16 ~ 2026-10-16**，共 **338 天、2875 个不同话题**；按"上榜天数"排序——这是唯一使用的"重要性"代理变量。
- **X（Twitter）**：按国家、按日期的历史趋势存档（twtData），采集**美/英/日**，每 14 天采样，共 **81 个"国家—日"**。
- **一个结构性发现**：知乎霸榜的是**恒久的人生问题**（低成本爱好、成长、焦虑、松弛感）+ 持续数周的事件；X 霸榜的是**体育与娱乐** + 间歇的政治/金融。**平台替你划线，而不同平台划的是不同的线。**

## 数据管线（可复现）

```bash
# 1) 当前热榜（知乎/头条/B站…）
python analysis/collect.py
# 2) 过去一年知乎每日存档 + 频次聚合
python analysis/fetch_archive.py           # -> data/year_zhihu.json, data/year_events.md
# 3) 过去一年 X 历史趋势（twtData + 无头 Chrome）
python analysis/collect_x_history.py       # -> data/year_x.json, data/year_x_events.md
# 4) 构建：书稿 Markdown -> HTML -> 插图/封面 -> PDF/EPUB/Markdown
bash scripts/build.sh
```

## 边界（本书不做什么）

- **不**判定任何热点事件的事实真相；只诊断讨论的**结构**。
- **不**声称六核诊断法能解释一切；每张卡都标注**证据等级**与**可反驳条件**。
- **不**把"上榜天数"当成"重要性"或"因果"——它只是一个**代理变量**。
