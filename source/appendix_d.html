附录 D　三十道自测题：你真的看见了吗

这份附录是一面镜子，不是考试。三十道题，六个核各五道；每题只要求“能举一个自己的例子”，不要求术语。能举例，才算会用；只会背定义，说明还在门口。

D.1　看见（区分）

  1. 你最近一次改变看法，是因为看到了一个新事实，还是因为换了一条分界线？
  2. 一条热搜把人群分成“我们／他们”时，被划出去的是谁？谁有资格划这条线？
  3. 你能不能举一个“被看见但不重要”的例子？再举一个“重要但没被看见”的例子？
  4. 如果换一个分类方式，同一个事实会变成另一个故事吗？
  5. 你上一次说“这不就是××吗”，是把复杂的事压成了哪个标签？

D.2　记住（容量）

  1. 一年前你转过的一条热搜，现在还记得多少？被忘掉的是细节还是结论？
  2. 你记住一个事件，是因为它重要，还是因为它好记（有画面、有数字、有人名）？
  3. 平台把一件事压成一个标签时，丢掉了哪三个条件？
  4. 你有没有“记得结论、忘了前提”的经历？那个结论后来还成立吗？
  5. 如果只能保留一条信息给一年后的自己，你选哪一条？为什么？

D.3　跟上（时间错配）

  1. 你最近一次“来不及”，是判断错了，还是判断对了但太慢？
  2. 一件事里，最快的钟与最慢的钟分别是什么？它们差几个数量级？
  3. 谁在充当“同步器”——把慢钟的问题拉到快钟上爆发？
  4. 如果给你多一周，你会多做什么？那一周真的能改变结果吗？
  5. 你有没有把“慢”直接读成“错”？举一个反例。

D.4　选择（C-A-T）

  1. 你最近做的一个决定，保住了哪两样、让出了哪一样？
  2. 有没有一个方案说“我全都要”？它后来在哪一步露出代价？
  3. 一个组织的“预算”是什么：钱、时间、注意力，还是信任？
  4. 如果预算减半，你会先砍哪一项？这一项为什么不是最不重要的？
  5. 你能不能举一个“让出一角反而更稳”的例子？

D.5　讲述（置信度）

  1. 你最近转发的一句话，属于事实层、诠释层，还是立场层？
  2. 你有没有把“我认为”说成“事实上”？当时缺的是哪一条证据？
  3. 一个说法若为假，我们会看到什么？如果答不出，它还是命题吗？
  4. 你同不同意“证据等级低的人不配发言”？为什么？
  5. 你能不能把一句立场句，改写成一句可核对的事实句？

D.6　临界（相变）

  1. 你身边有没有一个系统，表面平静，但每次冲击后恢复得更慢？
  2. “爆了”与“临界”有什么区别？举一个“爆了但不是临界”的例子。
  3. 什么量从“几乎没有”变成了“非零”？这个变化可逆吗？
  4. 变之前，系统有没有变慢、变脆、变同步？
  5. 如果明天一切照旧，你还会认为它“正在接近临界”吗？

用法：每周挑一个核，答五题；答不出的题，就是下周要观察的地方。三十题答完，你不需要这本书了——你已经有自己的六把尺子。

一句话带走：会用六核的标志，不是能背出六个词，而是能在自己的生活里，各举一个例子。
